# 7. 表格质量与数据表达

表格必须服务于正文中的比较、查阅或决策，不能只是把连续 prose 拆成多列。正文应说明表格要回答的问题，并在表格后解释关键差异；不要让表格替代必要的论证。

检查表头、行列含义、单位、精度、排序方式和空值含义是否明确且前后一致。每个数据项都应能追溯到正文论证、实验结果或可核验的参考来源；不同版本、环境和口径的数据不能混放或无提示比较。

检查表格是否存在重复列、难以比较的字段、误导性的排序或只展示有利数据的选择性呈现。需要时补充基线、范围、样本量、时间、版本、实验条件和来源；不要把推断值写成实测值。

表格避免使用可见的竖线和双横线。Markdown 表格以渲染后的边框为准。LaTeX 表格优先使用 `booktabs` 的 `\toprule`、`\midrule` 和 `\bottomrule`。用 `\multicolumn` 添加跨列表头，再用 `\cmidrule` 标出分组范围。

表头应写清列含义和适用的单位。指标有明确优劣方向时，用 ↑ 表示越高越好，用 ↓ 表示越低越好。文本左对齐，数值列整体居中。同列的小数优先按小数点对齐，并保持一致的显示精度。

用分组表头或标签组织相关结果。每张表集中回答一个主要问题。需要比较不同方法、数据集或设置时，用明确的属性列标出各行的差异。

表格 caption 不应只重复表头、行名或“表中展示了什么”。读者应能直接理解表格中的基本元素。caption 应说明表格为何出现、比较条件是什么，或指出读者需要关注的结论。没有额外信息时，删去冗余 caption。

检查 Markdown/HTML 表格的渲染、长文本、代码、链接和中英文混排是否可读，尤其是移动端。无法直接观察渲染效果时，只指出需要人工视觉复核，不臆测实际布局。
