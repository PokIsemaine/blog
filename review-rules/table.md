# 7. 表格质量与数据表达

表格必须服务于正文中的比较、查阅或决策，不能只是把连续 prose 拆成多列。正文应说明表格要回答的问题，并在表格后解释关键差异；不要让表格替代必要的论证。

检查表头、行列含义、单位、精度、排序方式和空值含义是否明确且前后一致。每个数据项都应能追溯到正文论证、实验结果或可核验的参考来源；不同版本、环境和口径的数据不能混放或无提示比较。

检查表格是否存在重复列、难以比较的字段、误导性的排序或只展示有利数据的选择性呈现。需要时补充基线、范围、样本量、时间、版本、实验条件和来源；不要把推断值写成实测值。

检查 Markdown/HTML 表格的渲染、长文本、代码、链接和中英文混排是否可读，尤其是移动端。无法直接观察渲染效果时，只指出需要人工视觉复核，不臆测实际布局。
