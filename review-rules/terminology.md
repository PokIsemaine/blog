# 4. 术语与概念统一

全文术语和概念必须统一。同一个概念始终使用含义一致的名称，不同概念不能混用。

已有通用叫法时，使用领域内已有的术语和缩写。不要生造名称、把几个词硬拼成术语，或为普通描述自创缩写。没有通用叫法时，用简短、具体的文字说明实际含义。

专业术语必须有可核验的引用或来源。缩写第一次出现时必须同时给出全写（中文或英文全称），之后才可以单独使用缩写；代码、标题和图注中的首次出现也适用。

术语首次出现时给出必要解释。核对中英文名称、示例与正文定义是否一致。遇到用词冲突或确认存在不必要的自造术语时，指出具体位置，并给出通行叫法或直接描述。判断术语是否通行应参考领域文献或官方文档中的用法。引用缺失或缩写缺少全写时，指出具体首次出现位置和补充方式。
