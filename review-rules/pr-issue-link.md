# 15. PR 必须关联 issue

每个 PR 必须在描述中关联至少一个 issue，便于追溯改动动机、讨论和验收范围。可接受的形式包括 `#123`、`owner/repo#123`，或完整的 GitHub issue 链接。`Closes #123`、`Fixes #123` 和 `Resolves #123` 会在合并时关闭对应 issue；只关联而不关闭时使用 `Refs #123`。

关联必须指向驱动本次改动的 issue，不能用无关编号凑数。只写在代码块、行内代码或 HTML 注释中的编号不算关联。PR 描述更新后，审阅会重新检查。

该规则在文章内容审查前由脚本检查。缺少关联时直接返回 reject，并提示补充关联；AI 内容审查不需要重复判断。空描述视为未关联。
