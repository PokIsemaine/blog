# 14. 学术表达适配

根据目标读者和论证目的调整表达。避免连续堆叠多个术语、缩写和修饰语。已有通用术语应保留，非必要的术语应改成直接描述。首次出现的关键概念给出足够的定义，解释应服务于理解当前论点。

一个句子只承担一个主要观点。把包含多个从句、转折和结果的长句拆成“核心句 + 支撑句”。主动语态和客观陈述都可以使用，根据句意选择清楚、自然的表达。不要为了追求形式统一而机械使用被动语态。

全文保持正式、稳定的语体。删除口语化、含糊或情绪化的表达。结论强度必须与证据相称。使用“表明”“支持”“提示”等表述时，应说明对应的结果和范围，不能把有限实验写成绝对结论。

面向跨学科读者时，为理解关键概念补充必要的背景、全称或简短解释。解释应靠近首次出现处，并在读者已经理解后停止，不要扩展成与主线无关的教程。

段落之间应有清楚的逻辑关系。观点发生转折、递进、因果或范围变化时，使用准确的连接方式，或补充一句必要的过渡。不要从一个观点直接跳到无关观点。

审核时指出具体误区、影响理解的句子或跳跃位置，并给出符合目标读者和证据范围的改写。
