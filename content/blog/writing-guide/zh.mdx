## 给代码提供上下文

代码块使用明确的语言和文件名，读者可以直接复制代码。

```sql title="lookup.sql" {2}
CREATE INDEX orders_customer_idx ON orders (customer_id);
SELECT * FROM orders WHERE customer_id = 42;
```

## 对比不同方式

## 展示完整流程

<Steps>
<Step>

### 编写

创建元数据完整的英文 MDX 文章，中文翻译准备好后再发布。

</Step>
<Step>

### 验证

运行内容校验、类型检查和生产构建，核对交互示例与正文结论。

</Step>
<Step>

### 发布

提交 PR，通过必要检查后合并，GitHub Actions 自动导出并部署。

</Step>
</Steps>

## 保留可展开的细节

<Accordions type="single" collapsible>
  <Accordion title="哪些内容应该放入可复用组件？">
    把交互行为和计算逻辑放入 React/TypeScript
    模块。文章侧重解释、假设和结果解读。
  </Accordion>
  <Accordion title="静态搜索索引包含什么？">
    包含已发布文章的标题、描述、章节与正文。草稿和仅在交互组件运行时生成的文字不会被索引。
  </Accordion>
</Accordions>

<Callout title="测量结果不等于性能保证" type="warn">
  在结果旁说明工作负载假设和局限。小型浏览器实验不能证明生产数据库的性能。
</Callout>
